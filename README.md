# BountyLens

> Geofenced DePIN Proof-of-Physical-Work Mobile App built for Solana

BountyLens is a mobile-first application where users complete real-world geo-verification tasks (photo proofs, location verification, infrastructure monitoring) and earn rewards.

---

### Tech Stack
* **Frontend:** React Native / Expo (TypeScript)
* **Backend & Auth:** Supabase (PostgreSQL, Storage, RLS)
* **Blockchain:** Solana Wallet Integration / Mobile Wallet Adapter

---

### Core Features
* **Geo-fenced Bounties:** Interactive map with tasks pinned to precise GPS coordinates.
* **Proof Submission:** In-app photo & metadata capture for instant verification.
* **Secure Backend:** Supabase row-level security and automated database checks.
* **Wallet Integration:** Seamless web3 payout flow for field workers.

---
